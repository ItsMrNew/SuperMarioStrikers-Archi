Super Mario Strikers Archipelago - Dolphin patch

Requires Super Mario Strikers (USA), game ID G4QE01.

1. Close the game.
2. In Dolphin, choose File > Open User Folder.
3. Copy this folder's inner Riivolution folder into the user folder's Load folder.
   The finished paths should be:
     Load/Riivolution/StrikersAP/main.dol
     Load/Riivolution/riivolution/StrikersAP.xml
4. Right-click the USA game and choose Start with Riivolution Patches.
5. Enable "Completion mailbox and DeathLink goals" and start the game.
6. Open Super Mario Strikers Client in Archipelago Launcher and connect to
   your room using your player name.
7. Wait at the title or main menu until the client confirms the save is ready.

Install the accompanying strikers.apworld as well as this patch.
Use a fresh save for each new seed and keep the client running while playing.
Save through the game's normal memory-card system.

Select your preferred difficulty when creating a cup. An existing cup keeps
the difficulty it was created with.

The XML loads the supplied main.dol without changing your game image.
No game image is included.

See the main README.txt for YAML choices, checks and troubleshooting.
